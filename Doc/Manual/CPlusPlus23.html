11.1 Introduction

This chapter gives you a brief overview about the SWIG implementation of the C++23 standard. Work has not yet begun on adding support for the core language features introduced by C++23.

SWIG accepts -std=c++23 on the command line. As for every other standard, the only effect of the option is to set __cplusplus to the value for that standard, 202302L, so that a header with preprocessor checks on the value is handled the way a C++23 compiler would handle it. The option does not gate the grammar, so it does not otherwise change what SWIG parses. See Conditional Compilation in the preprocessor chapter for the full list of standard macros SWIG defines.

11.2 Core language changes

No C++23 core language feature is explicitly supported yet.

11.3 Standard library changes

The SWIG library does not yet wrap any of the containers and types added to the standard library by C++23.
